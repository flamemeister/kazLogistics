# Canonical GSLog header logo

Selected by the owner on 2026-11-12: the artwork currently used in the production header.

- Source: https://gslog.kz/assets/logo_new_3-Csj9INUs.png
- Original dimensions: 2208 × 734, opaque green matte.
- Original SHA-256: `e9c47a7bbd3be86da95b38b28b2390ad1ff069388811d118e4c0cf4f37414647`.
- The original copy is kept in the ignored `original/brand/` directory.

The selected derivative preserves the original artwork; its green matte (`#24502a`) was removed using the local chroma-key helper with a soft alpha edge, without redrawing/retyping the logo. An image-generation removal attempt was rejected because it introduced artifacts and is not used by the site.

Current assets:

- `gslog-header-2026.webp`: transparent web logo, 640 × 213.
- `../email/logo-header-2026.png`: transparent PNG for email clients, 640 × 213.

The header, footer, flight dialog and new emails use this same artwork. Earlier logo files are retained for compatibility with previously sent email image URLs; do not reintroduce them into current layouts.
